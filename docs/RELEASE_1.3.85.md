# Stormforge DiskManager 1.3.85

修复 UASP 硬盘点击弹出时被误判为“非外置硬盘”：GUI 和兼容入口传递磁盘身份时保留已验证的外置标记。休眠状态的列表记录也保留该标记，避免界面错误显示为内置或禁用管理操作。继续保留白名单、设备身份及实际 USB 总线校验，不把全部 SCSI 硬盘视为外置。

修复发布包缺失日志上传配置：内置仅供上传的客户端配置，构建时缺少配置会报错。服务器分别验证客户端上传凭据和管理端报告访问凭据；客户端凭据不能浏览或下载报告。管理配置不随发行包或公开源码分发。

关机流程保持 v1.3.84 已验证实现。测试包括弹出身份传递、休眠列表、内置盘排除、内置配置读取，以及使用合成 ZIP 的服务器上传和读取拒绝检查。用户机器的完整弹出仍需实测；截图中的 SCSI/ATA 报错本身不能证明设备为内置盘。
