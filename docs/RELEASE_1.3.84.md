# Stormforge DiskManager 1.3.84

目标：关机持续停转，并减少停转后存储请求超时带来的关机等待。

用户确认：离线、卸载是手段而非禁止条件；不能卸载的盘仍应尝试停转。验收以持续停转和实机关机时间为准。

恢复历史 PRESHUTDOWN 流程：核对目标盘身份 → 刷新缓存 → 尝试临时离线 → ATA SLEEP。仅操作 GUI 白名单中的外置盘；离线失败仍尝试 SLEEP。离线状态下 SLEEP 返回失败时，尝试恢复在线并最多重试一次 SLEEP，不回退到 STANDBY、不重置硬盘柜。

离线使用 Persist=False，预期在下次设备重新枚举后恢复在线。不按上次保存的磁盘编号批量上线，避免影响其他硬盘。服务处理上限设置为 30 秒，并非固定等待；同步存储调用仍受 Windows 驱动行为影响，不能承诺每次关机都在该时限内完成。

命令成功后只关闭句柄，不继续探测或刷新该盘。日志分别记录缓存准备、临时离线和总处理耗时，以及是否保持离线。若离线失败，仍可能出现 Windows 存储超时或控制器复位。

使用：退出旧版，完整解压，以管理员身份运行 Stormforge_DiskManager_v1.3.84.exe，核对“纳入管理”的硬盘。关机前保存文件，关闭使用这些文件的软件，等待复制、移动、下载和备份完成。

验证：模拟测试覆盖白名单、身份不符、离线失败、缓存刷新失败、离线透传回退、系统盘保护及服务通知。实机关机需确认硬盘保持停转、关机耗时缩短；仅凭 SLEEP 返回成功或单项 SMART 计数不能证明数据安全或停转持续到断电。
