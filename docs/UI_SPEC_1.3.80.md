# Stormforge DiskManager UI 规范

版本：1.3.80  
适用范围：Windows 桌面客户端主窗口、弹窗、系统托盘菜单和状态反馈。

## 1. 设计目标

界面按用户任务组织，而不是按内部模块组织。用户进入程序后应按以下顺序完成操作：

1. 在左侧选择硬盘并决定是否纳入管理。
2. 在右侧确认当前硬盘状态。
3. 执行立即休眠或停转并安全弹出。
4. 在“概览”“SMART 参数”“设置”中查看或调整信息。

所有会改变硬盘状态的操作都必须从当前选中的硬盘上下文发起。未纳入管理的硬盘只显示设备信息，不接受 SMART、休眠、弹出或关机停转命令。

## 2. 颜色系统

颜色沿用正式版的深色、紫色和绿色组合。颜色同时配合文字、边框或图标表达状态，不能只依赖颜色。

| 用途 | 色值 | 使用规则 |
| --- | --- | --- |
| 主背景 | `#0C0C0C` | 主窗口和页面空白区域 |
| 侧栏与卡片 | `#1A1A1A` | 设备列表区域、信息卡片、弹窗 |
| 列表项 | `#262626` | 未选中的硬盘项、表头 |
| 悬停/选中表面 | `#2D2D2D` / `#333333` | 悬停、选中和菜单高亮 |
| 结构边框 | `#2D2D2D` | 卡片、列表项、表格和分隔线 |
| 主要紫色 | `#9147FF` | 当前选择、立即休眠、标签页、频率滑块 |
| 紫色悬停 | `#A66DFF` | 紫色按钮悬停状态 |
| 安全绿色 | `#76B900` | 安全弹出、健康状态、确认成功 |
| 绿色悬停 | `#88D000` | 安全弹出按钮悬停状态 |
| 正文 | `#FFFFFF` | 硬盘型号、标题、主要数据 |
| 次要文字 | `#AAAAAA` | 状态说明、提示和辅助信息 |
| 警告文字 | `#FFD18B` | 关机前保存数据、风险提醒 |

绿色只用于安全完成和健康状态。紫色用于当前选择和可逆的休眠操作。橙色警告区域只用于要求用户采取行动的风险提示。

## 3. 窗口与间距

- 默认窗口为 1220×800，最小窗口为 1040×680。
- 左侧硬盘栏宽度固定为 330px；右侧内容区域自适应。
- 主窗口边距为 28px（上、右、下、左），主要区块间距为 16px。
- 卡片圆角为 8px，边框为 1px `#2D2D2D`。
- 硬盘列表项高度约 78px，列表项之间保留 3–4px 间距。
- 不使用大面积渐变、阴影或装饰性边框；边框只用于区分结构和交互区域。

## 4. 字体层级

- 窗口主标题：25px，加粗，紫色。
- 硬盘型号：16px，加粗，白色。
- 区块标题：16px，加粗，绿色。
- 正文和表格：14px，白色。
- 状态与提示：13–14px，灰色；不得低于 12px。
- 不用全大写，不在同一行混排型号、状态和操作说明。

## 5. 页面结构

### 左侧硬盘栏

从上到下依次为品牌标识、硬盘列表标题、白名单说明和硬盘列表。每一行左侧固定放置 22px 复选框，文案使用“纳入管理”或“✓ 已管理”；右侧使用两行显示硬盘型号和状态。

选中项使用 `#333333` 背景和紫色边框。悬停只改变背景，不改变管理状态。序列号缺失、内置硬盘或非 USB/UASP 设备的复选框禁用，并显示原因提示。

### 右侧操作区

顶部固定显示关机数据提示。提示包括明确标题：“关机前请先保存并关闭硬盘柜内的数据”，以及文件、下载、备份和索引任务的示例。

提示下方显示当前硬盘型号、状态和两个操作：

- “立即休眠”：紫色，用于可逆的休眠操作。
- “停转并安全弹出”：绿色，用于卸载、停转和 Windows 安全弹出。

未选中或未纳入管理时，两个操作均禁用，并在悬停提示中说明原因。

### 标签页

- “概览”：基本信息和健康建议。
- “SMART 参数”：完整 SMART 表格和解释。
- “设置”：当前硬盘监控频率、自动休眠时间、保护状态和应用维护。

标签页只改变内容视图，不改变当前硬盘选择，也不触发硬盘读写。

## 6. 交互与状态规则

- 加入白名单后，立即更新复选框文案、操作按钮和后台监控权限。
- 移出白名单后，停止该硬盘的 SMART、自动休眠、弹出和关机停转任务。
- 执行操作期间，按钮显示进行中状态并禁用重复点击。
- 操作完成后，状态文字必须说明成功、失败或需要用户采取的下一步。
- 风险确认弹窗的默认按钮必须是“取消/否”；确认文字必须说明可能影响和恢复方式。
- “刷新硬盘状态”只做只读状态刷新，并提示设备未出现时重启对应硬盘柜。

## 7. 可读性与可访问性

- 关键文字保持 12px 以上，硬盘型号保持 16px。
- 复选框、按钮和滑块的有效点击区域不小于 36px 高。
- 状态同时显示文字和颜色，例如“Healthy / Warning / Sleeping”。
- 每个禁用控件提供原因 Tooltip。
- UI 不使用只有颜色才能理解的提示，不用空白或不可见控件承载核心操作。

## 8. 版本验收清单

- 左侧只包含硬盘选择和白名单入口。
- 右侧顶部始终能看到关机前保存数据的提示。
- 安全弹出为绿色主操作，立即休眠为紫色次操作。
- 卡片、表格和列表项使用统一的深灰边框和 8px 圆角。
- 所有用户可见文案使用正式版措辞，不出现临时构建名称。
